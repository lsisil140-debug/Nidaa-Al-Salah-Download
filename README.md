# تطبيق نداء الصلاة

**نداء الصلاة** تطبيق إسلامي يجمع مجموعة من الخدمات والميزات التي تساعد المستخدم على متابعة شؤونه التعبدية اليومية، من خلال واجهة سهلة الاستخدام وتجربة عصرية.

## مميزات التطبيق

- **مواقيت الصلاة:** عرض أوقات الصلوات والتنبيه عند دخولها.
- **القرآن الكريم:** الوصول إلى سور القرآن الكريم وقراءتها.
- **الأذكار والأدعية:** قسم مخصص للأذكار والأدعية.
- **اتجاه القبلة:** المساعدة في معرفة اتجاه الكعبة المشرفة.
- **التنبيهات:** إشعارات لمتابعة أوقات الصلاة.
- **تحديثات التطبيق:** إشعارات عند توفر إصدارات جديدة.

## التحميل والتحديثات

هذا المستودع مخصص ليكون الصفحة العامة الرسمية لتطبيق **نداء الصلاة**. ستُنشر فيه معلومات التطبيق وروابط تنزيل إصداراته، مع متابعة التحديثات والإصدارات الجديدة.

يمكنك زيارة قسم [الإصدارات (Releases)](../../releases) للاطلاع على النسخ المنشورة وتنزيلها.
